# JS AI Chess Engine

A zero-dependency, browser-based chess engine built in vanilla HTML5, CSS3, and JavaScript. Features a Minimax AI opponent with Alpha-Beta pruning, full chess rule validation, and procedural Web Audio sound synthesis.

## Live Demo
Play directly in your browser: https://sumitjajoriya57.github.io/ai-chess-engine/

## Features
- **AI Opponent:** Minimax search algorithm with Alpha-Beta pruning across 3 difficulty depths.
- **Positional Evaluation:** Uses Piece-Square Tables (PST) and material piece weights.
- **Full Chess Rules:** Supports castling, en passant, pawn promotion, check, and checkmate detection.
- **Audio & UI:** Synthesized Web Audio API sound effects, move history log, captured pieces tracker, and undo functionality.
